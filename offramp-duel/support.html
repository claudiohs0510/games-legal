Offramp: Support

How do I play?

Tap an arrow. It slides the way it points until it leaves the board or hits something, and if it hits something it parks there. Clear every arrow. Black blocks never move, and blue turn tiles steer an arrow onto a new heading.

What is par?

The fewest taps that clear the level, found by checking every possible route. Match it for three stars.

How do I send a maze?

Open Draw, build it and tap Check & Send. If the solver finds a way out you can share the code. Your friend opens Sent, pastes the whole message and taps Start Duel.

The code won't load.

Paste the whole message. Codes start with OFR. and include a checksum, so a mistyped or cut-off code is rejected instead of loading the wrong maze.

"Too tangled to prove"?

The maze has too many possible move orders to check on the phone. Remove a few arrows and check again.

Ads.

Only an optional video for the second and later hint in a level. Never during a duel.
